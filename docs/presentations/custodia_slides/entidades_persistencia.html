Esquema DB

Cinco entidades SQLite para hacer persistente la responsabilidad

synthetic_agents

Identidad de agentes, proveedor (DeepSeek/local), modelo configurado, mandato base y estado activo.

agent_id (PK), provider, model, mandate
admin_sessions

Contrato de sesión: convocante, mandato, scope, hash de contexto, presupuesto de requests y caducidad.

session_id (PK), convener_id, status, expires_at
session_permissions

Matriz normalizada de permisos (P0 lectura, P1 propuesta, P3 prohibiciones) asignados por sesión.

session_id, permission_level, action
session_events

Bitácora inmutable: creación, llamadas a herramientas, salida del oráculo, rechazos y revocaciones.

id (PK), session_id, event_type, payload_json
session_reviews

Decisión humana formal (approve, reject, request_changes) con razón obligatoria para trazabilidad.

session_id, reviewer_id, decision, reason
