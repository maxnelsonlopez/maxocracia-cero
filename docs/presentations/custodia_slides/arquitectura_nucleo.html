03
Arquitectura

La arquitectura reutiliza el núcleo existente

PASO 1
Panel Admin (Next.js)

UI de deliberación y revisión en /admin/synthetic-sessions. Se comunica vía Bearer JWT.

PASO 2
Blueprint Flask

Rutas en synthetic_sessions.py validan identidad admin, aplican matriz P0-P3 y redacción.

PASO 3
Oráculo Server-Side

DeepSeek API como proveedor primario con fallback a hub Jan local (localhost:1337).

PASO 4
Memoria SQLite

Persistencia de contrato, bitácora de eventos y decisiones de revisión con firma y trazabilidad.

Claves en Servidor

La API key nunca viaja al navegador. El cliente solo recibe el análisis estructurado.

Fallback Transparente

Degradación elegante hacia modelos locales ante fallos de conexión o límite de cuota.

Sin Mutación Directa

El modelo no tiene acceso a SQL libre ni a llamadas REST de escritura sobre tablas vivas.
